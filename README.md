# Interfaz Web Resiliente y Multirrubro para Airtable

Plataforma web dinámica, segura y adaptable para la gestión de registros (Pacientes / Clientes / Socios) y citas/turnos conectada en tiempo real con Airtable.

## Características Principales

- **Resiliencia de Esquema**: Formularios y tablas autogenerados según los campos activos en Airtable. Inmune a columnas agregadas o eliminadas.
- **Multirrubro (White-Label)**: Paletas visuales y terminología adaptable (Estética & Spa, Clínica / Salud, Fisioterapia / Rehab, Gimnasio / Fitness).
- **CRUD Completo y Seguro**: Creación, consulta, edición y eliminación de registros con sanitización de payloads y modales de confirmación.
- **Seguridad**: Tokens y credenciales protegidos en el backend (`.env`). Autenticación mediante JWT.
